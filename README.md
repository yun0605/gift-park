# 口袋乐园 · POCKET PARK

> 一座装进口袋送给你的小小乐园。单文件 `index.html`、零外部请求、全原创插画与 Web Audio 合成音效，手机竖屏打开即可游玩。

---

## 快速开始

- **本地打开**：直接用手机或电脑浏览器打开 [`index.html`](./index.html) 即可游玩（推荐手机竖屏体验；电脑端会自动居中呈现手机画框）。
- **发送给朋友**：将单个 `index.html` 发送给对方，或托管到任意静态页面服务（如 GitHub Pages / Cloudflare Pages / Vercel）。
- **麦克风吹蜡烛说明**：现代浏览器仅在 `https://` 或 `localhost` 环境下允许访问麦克风；若通过本地 `file://` 打开或拒绝麦克风权限，蛋糕场景会自动切换为同样好玩的「长按吹气」按钮模式，体验完全不受影响。

---

## 玩法说明

1. **门票入场**
   - 按住门票左侧的柠檬金小拉片，沿打孔虚线向右拖动撕开门票（也可多次点击拉片逐步推进）。
   - 撕开后进入简短开园动画（轻点屏幕任意处可跳过），抵达手绘「乐园地图」。
2. **自由漫游四个站点（可任意顺序，顶部站牌条支持随时跳站）**
   - **01 旋转木马音乐盒**：顺时针拖动或轻点右下角黄铜发条钥匙上弦；上弦越多转得越久、灯光越亮，八音盒旋律随发条能量自然起伏与减速。听完一遍完整旋律即可获得**印章①**。
   - **02 幸运扭蛋机**：顺时针旋转或点击旋钮，扭蛋滚落出口后轻点打开，收获 12 件原创插画小物件（星星瓶、纸飞机、热气球、四叶草、棒棒糖、小火箭、月亮船、彩虹伞、玻璃鞋、时光沙漏、许愿灯、小信封）与一句暖心文案，优先不重复掉落。首次开蛋获得**印章②**；可在下方「口袋收藏」随时回顾已收集的物件。
   - **03 时光拍立得**：按下大号快门按钮（或相机顶部的红色快门），闪光出片后等待相纸从全白模糊慢慢显影成原创插画（星夜摩天轮、海边日落、热气球清晨、雪夜小屋轮换）。显影过程中轻点相纸可“甩一甩”加速；显影后可点击题字旁的小铅笔修改题字。首张照片显影完成获得**印章③**。
   - **04 许愿蛋糕**：对着 5 根蜡烛许愿并选择「用麦克风吹」或「用按钮吹」。麦克风模式下对着手机底部吹气，火焰会随气流摇曳并逐根熄灭；若不可用或 6 秒无输入会自动降级为「按住吹气」按钮。吹灭全部蜡烛后房间亮灯撒花，获得**印章④**（之后仍可点击「再点一次蜡烛」重玩）。
3. **终点 · 星光广场（烟花与信）**
   - 随时点击顶部中央的**印章托盘**打开「乐园护照」查看进度（或重置旅程）。
   - 集齐 4 枚印章后，前往地图顶端的「星光广场」触发开锁开门仪式：欣赏全屏烟花秀（支持牡丹、圆环、金柳、爱心、碎星五种礼花与三连齐射，**轻点夜空任意处还能亲自放一发烟花**），随后拆开火漆信封阅读信件。

## 如何修改信件文案

你有两种方式定制终点信件：

### 方式一：直接在页面上修改（推荐，适合送出前试玩或留给对方写）
1. 进入终点「星光广场」并拆开信封展开信纸。
2. 点击信纸下方的 **「✎ 修改」** 按钮，问候语、正文与署名区域会进入编辑态（带虚线外框与金色光环，烟花自动暂停以免干扰）。
3. 直接编辑文字，完成后点击 **「✓ 保存」**，内容将自动保存在当前设备的浏览器本地存储（`localStorage`）中。
4. 如需还原原始祝福语，连续两次点击 **「↺ 恢复默认」** 即可（3 秒内二次确认）。

### 方式二：在源码中预置专属默认文案（适合发给朋友前定稿）
用文本编辑器打开 `index.html`，搜索 `DEFAULT_LETTER`，修改其中的 `greeting`（问候语）、`body`（正文段落数组）和 `sign`（署名）即可。保存后发送给对方，对方首次打开就会看到你写好的信。

## 如何更换拍立得照片

拍立得场景默认使用 4 幅代码绘制的原创插画，不放任何照片也完全成立；如果你希望放入一张自己的照片：

1. 进入 **「03 时光拍立得」** 场景。
2. 点击快门按钮旁的 **「换成我的照片」**，从相册或本地选择任意图片。
3. 页面会在浏览器本地自动将其居中裁切为 `720×720` 正方形并走一遍完整的**快门闪光 → 出片 → 显影**流程，显影后同样可以点击题字旁的铅笔图标自定义题字（默认「这一刻，留给你」）。
4. 照片**仅保存在当前设备的浏览器本地**，不会上传到任何服务器；点击 **「恢复为插画」** 可随时清除照片、恢复纯插画轮换。

## 技术特点

- **单文件、零外部依赖**：全部图标、场景插画、12 件扭蛋物件、4 幅拍立得风景均由内联 SVG 与 Canvas 绘制；纸纹与印章斑驳使用内联 `data:` URI SVG 滤镜，网络请求为 0。
- **全合成 Web Audio 音效**：撕纸、检票戳、开园琶音、发条/旋钮棘轮、八音盒原创旋律、扭蛋滚落与开蛋、快门与出片马达、吹气与熄灭、撒花、烟花哨音与爆炸均由 Web Audio 实时合成，右上角提供全局静音开关。
- **隐私与本地状态**：所有进度、收藏、自定义题字/信件与可选照片均存储在 `localStorage`（前缀 `pocketpark.v1.*`），在「乐园护照」底部可一键重置旅程（保留你写好的信件与照片）。
